# 🌌 Система частиц хаоса (Chaos Particles)

## 📁 Расположение
- `src/components/ChaosParticles.jsx` — вся логика, рендер, физика, конфигурация
- `src/components/ChaosParticles.css` — позиционирование, z-index, прозрачность
- Используется в: `src/pages/TaskScreen.jsx` (и будущих экранах игры)

## 🏗️ Архитектура
- **Canvas + rAF**: Отрисовка на `<canvas>` через `requestAnimationFrame`. Цикл синхронизирован с частотой обновления экрана (обычно 60 FPS).
- **Portal в `<body>`**: Компонент монтируется напрямую в `document.body` через `createPortal`. Это гарантирует покрытие 100% viewport, независимо от `transform`, `filter` или `overflow` родительских React-компонентов.
- **Координаты мыши**: `e.clientX / e.clientY` напрямую совпадают с пикселями канваса. Никаких смещений `getBoundingClientRect` внутри анимационного цикла.
- **Синхронизация с ядром**: Получает `chaosEnergy` (0–100) и `riftStage` (0–3) из родительского компонента. Влияет на множитель скорости, пульсацию искр и цветовые акценты.

## ⚙️ Конфигурация (в начале `.jsx`)
Все настройки вынесены в объект `const CONFIG` в первых строках файла.

| Параметр | По умолчанию | Что меняет | Примечание |
|----------|--------------|------------|------------|
| `total` | `60` | Макс. кол-во частиц на экране | Оптимум: 40–80. >100 может снизить FPS на мобильных |
| `mouse.radius` | `220` | Зона реакции (px) | Частицы внутри этого радиуса отталкиваются от курсора |
| `mouse.force` | `0.5` | Сила толчка | `0.2` = мягко, `0.8` = резко. Не ставь `0` если нужна реакция |
| `mouse.friction` | `0.90` | Сопротивление среды | `0.95` = быстро тормозят, `0.80` = долго скользят |
| `types.dust.ratio` | `0.60` | Доля "пыли" (бессмертные) | Должно быть `< 1.0` |
| `types.glow.ratio` | `0.30` | Доля "свечения" (бессмертные) | Сумма `dust + glow` должна быть `< 1.0` |
| `types.spark.*` | `{ ratio: 0.10, lifeMin: 2, lifeMax: 4 }` | Искры (живут циклом fade-in → fade-out → респавн) | `immortal: false` |
| `colors.*` | Массивы `rgba(...)` | Палитра по типам | Можно добавлять свои HEX/RGB, но формат `rgba` удобнее для прозрачности |

## 🔌 Пропсы (входные данные)
```jsx
<ChaosParticles 
  chaosEnergy={0..100}   // Энергия хаоса. Множитель скорости: 1.0 + (energy/100)*0.3
  riftStage={0..3}       // Стадия разлома. При >=3 искры получают пульсацию и смену цвета
  enabled={true}         // Вкл/выкл рендера. Автоматически `false` во время `loading`
/>
```

## 🛠️ Как менять настройки
1. Открой `src/components/ChaosParticles.jsx`
2. Найди `const CONFIG = { ... }` в самом верху
3. Измени числа. Сохрани.
4. **Важно:** при изменении `total` или `ratio` перезагрузи страницу (`Ctrl+Shift+R`), так как массив частиц пересоздаётся только при инициализации или ресайзе.
5. Для проверки реакции мыши временно верни дебаг-круг (раскомментируй строки с `ctx.arc(mx, my, ...)` в `animate()`).

## 🐛 Отладка и частые вопросы
| Проблема | Причина | Решение |
|----------|---------|---------|
| Частицы не реагируют на мышь | `force = 0` или перекрытие событий | Проверь `CONFIG.mouse.force`. Убедись, что над канвасом нет элемента с `pointer-events: auto` |
| Круги/частицы сплющены | Рассинхрон CSS-размера и `canvas.width/height` | В текущей версии решено через `window.innerWidth/Height` + `inset: 0` в Portal. Не меняй CSS на `width: 100vw` |
| Частицы исчезают и не возвращаются | `life` у `spark` слишком мал или `isRespawning` зациклился | Проверь `types.spark.lifeMin/Max` и `currentOpacity` пороги в `animate()` |
| Низкий FPS | Слишком много частиц или тяжёлые градиенты | Снижай `total`, убирай `mix-blend-mode` в CSS, отключай отладочные `console.log` |

## 📊 Производительность
- **Рендер:** 1 Canvas-слой, без DOM-узлов на частицы
- **Память:** ~50-60 объектов в массиве `particlesRef`. При респавне объект переиспользуется, а не создаётся заново
- **Очистка:** `cancelAnimationFrame` + удаление Portal-контейнера при `unmount` или `enabled=false`
- **Оптимизации:** `Math.hypot` вместо `sqrt(dx*dx+dy*dy)`, вынос `CONFIG` за пределы компонента, пассивные листенеры `{ passive: true }`

## 📝 История изменений
- `v2.4.1`: Перенос в React Portal, фикс координат мыши (`clientX/Y`), синхронизация разрешения, бессмертные `dust/glow`, плавный респавн `spark`, удаление `mix-blend-mode` для стабильности
